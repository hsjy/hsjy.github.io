## 前提
1. 制作一块ubuntu系统的启动盘（[Rufus](https://rufus.ie/zh/)）；
2. Windows预留一块未分配的存储空间（存放linux系统）
![distribute_disk](assets/img/posts/26-1/win_ubuntu/distribute_disk.png)

## 安装ubuntu系统
1. 将制作好的U盘插上电脑，重启，连续按F12（不同机器可能按键不同）进入启动设备选择页面，通过USB启动。
2. 进入Ubuntu安装页面，选择`try or install ubuntu`.
3. 在安装类型页，选择“其他选项”（自定义安装位置）。
![install_location](assets/img/posts/26-1/win_ubuntu/install_location.jpeg)
4. 找到未分配的那块存储空间，确定大小是否与预存留的空间一致，点击左下角`+`号，创建分区，挂载点选择`/`，将这个分区挂载为系统的根目录。
![create_boot](assets/img/posts/26-1/win_ubuntu/create_boot.png)
5. 等待安装成功...

> 另一种做法是将linux的根目录挂载到这块存储空间的一个分区，剩下的存储空间新建一个分区挂载为`/home`作为用户空间，以此将linux系统与用户数据分开。例如，假设有500G的未分配空间，那么我选择250GB创建一个分区作为`/`，剩余的250GB创建一个分区作为`/home`

## 安装显卡驱动
进入ubuntu后，装显卡驱动。
有两种方式：一是通过“软件与更新”程序，选择附加驱动，安装合适版本，比较方便。二是通过官方`.sh`文件安装。
这里我采用第二种方式。

首先，根据显卡版本选择驱动：<https://www.nvidia.com/en-us/drivers/>
之后运行`.sh`文件遵照流程安装即可。

只是中间有几个需要注意的点⚠️：
- 当出现`“Multiple kernel module types are available for this system. Which would youlike to use?”` 时，根据显卡架构的新旧选择`NVIDIA Proprietary`或`MIT/GPL`
- 运行`.sh`文件前，确保系统已经安装好了gcc, g++, make, 注意要与内核版本一致。比如，如果驱动编译需要g++ 12,gcc 12，而系统默认apt install的是11，这时候需要进行版本切换（[参考链接](https://blog.csdn.net/qq_42091428/article/details/147352681)）
- 关闭 BIOS 安全启动，忽略 NVIDIA 内核模块数字签名。

## 安装cuda toolkit
1. 官方网站：[CUDA Toolkit Archive](https://developer.nvidia.com/cuda-toolkit-archive)
选择合适版本，下载（runfile）。
2. 安装，进入安装引导页。  
**Attention:** 安装过程中取消驱动安装，在Driver那里按下Enter键使之变为非框选状态（如下图），只安装CUDA Toolkit 12.4, 接着移动至`Install`
![cuda-installer](assets/img/posts/26-1/win_ubuntu/cuda_installer.png)
3. 设置环境变量  
到`/usr/local`中查看cuda名称，之后更改环境变量。将下述内容，添加至`~/.bashrc`中，`source ~/.bashrc`。`nvcc --version`验证。
```
export CUDA_ROOT="/usr/local/cuda"
export PATH="${CUDA_ROOT}/bin:$PATH"
export LD_LIBRARY_PATH="${CUDA_ROOT}/lib64:$LD_LIBRARY_PATH"
export CUDA_HOME="${CUDA_ROOT}"
```

## 时钟设置
**现象：**当安装双系统后发现两个系统时间不一致，Windows默认将硬件时钟视为本地时间（Local Time），而Linux / macOS默认视为协调世界时（UTC），然后根据系统设置的时区在软件层面进行换算。

**解决方案：**在windows端操作
- 1.打开注册表编辑器：按下 Win + R 键，输入 regedit，回车
- 2.进入路径`HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\TimeZoneInformation`
- 3.新建一个 DWORD (32-bit) 值，命名为`RealTimeIsUniversal`，将“数值数据”改为 1，基数选择“十六进制”或“十进制”均可。
- 4.重启，时间一致

## Grub启动
**现象：**电脑开机后跳过系统选择页面直接进入windows

**原因：**电脑的默认启动项是 Windows Boot Manager，不会经过 GRUB，而GRUB 是 Linux 的启动引导程序，只有先启动 Linux 才会进入 GRUB。

**解决：**在BIOS启动项中将Ubuntu移动到 Windows Boot Manager之前。
